# Iris Flower Classification

## CodeAlpha Data Science Internship Project

This project is based on Machine Learning and focuses on classifying iris flowers into different categories using flower measurements.

The machine learning model is trained using the famous Iris dataset and predicts flower categories based on features such as sepal length, sepal width, petal length, and petal width.

## Objective

The main objective of this project is to understand the basic concepts of machine learning classification and prediction using Python.

## Technologies Used

- Python
- Scikit-learn
- Pandas
- Matplotlib
- Google Colab

## Machine Learning Algorithm

- Random Forest Classifier

## Features of Project

- Dataset Loading
- Data Visualization
- Model Training
- Prediction System
- Accuracy Evaluation

## Flower Categories

- Iris Setosa
- Iris Versicolor
- Iris Virginica

## Project Outcome

The model successfully classified iris flowers with high prediction accuracy.
